# Bulk 默认分析分支

本文件只是参考方案已纳入 Bulk 模块后的条件性实施模板。由参考方案决定实际模块和顺序；只对已选模块应用本文件的工具选择、图型和质量门槛。

## 执行顺序

1. 样本与表达质控：样本ID、分组、配对、批次、临床协变量、PCA和离群样本。
2. 差异分析：根据数据类型选择 DESeq2、edgeR 或 limma，预先写明对比方向和协变量。
3. ORA：分别对显著上调、显著下调和必要时全部显著基因富集，报告背景基因集。
4. GSEA：对全部可检验基因按有方向统计量排序；不得只输入显著 DEG。
5. WGCNA：使用经质控、低表达过滤和适当变换后的表达矩阵；不得用 DEG 预筛代替独立模块发现。
6. 关联模块特征向量与疾病、连续表型或临床结局，报告效应、P值、多重校正和模块稳定性。
7. 参考方案要求 Bulk 内部候选汇合时，汇合 DEG、疾病相关模块基因、GSEA leading-edge 和预先定义的表型基因集。
8. 参考方案要求优先集合二次富集时，执行该分支并保留集合大小、背景和空结果。

## WGCNA–GSEA交集的停止规则

只在参考方案明确要求 WGCNA–GSEA 交集时启用本节。先固定疾病相关模块、GSEA显著性阈值、leading-edge定义和基因ID映射，再计算交集。若交集为空、基因数不足以富集或没有稳定可解释结果：

1. 直接报告“未获得满足预设条件的WGCNA–GSEA交集结果”；
2. 交付带稳定表头的空成员表、交集计数、所用阈值和失败原因；
3. 不生成Venn或富集占位图；
4. 不事后放宽P值、改变模块、改用任意top基因、扩大leading-edge或反复更换数据库以制造交集；
5. 保留WGCNA和GSEA各自有效的独立结果，但停止依赖该交集的候选基因与二次富集分支。

## 方向检查

把对比写成 `pathology - control` 或等价明确定义。此时正 logFC 表示病理组升高，负 logFC 表示病理组降低。通过设计矩阵、原始组均值、箱线图和热图核对；热图不能决定正负方向。

## 集合与图形

- 四组以内使用 Venn，超过四组使用 UpSet。
- 同时交付集合计数表和完整成员表。
- 富集结果交付 full/filtered 表；无显著结果时保留稳定表头，不生成占位图。
- 交集很小时避免夸大 ORA；优先呈现单基因证据矩阵或排名证据。

## 解释边界

同一 Bulk 队列的 DEG、GSEA 和 WGCNA 是互补视角，不是三个独立验证队列。模块—疾病相关不等于模块导致疾病。连续表型优先保留效应量，不要仅为制作 Venn 将其任意二值化。
