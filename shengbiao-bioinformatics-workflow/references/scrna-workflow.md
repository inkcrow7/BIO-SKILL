# 单细胞默认分析分支

本文件只是参考方案已纳入单细胞模块后的条件性实施模板。由参考方案决定实际模块和顺序；只对已选模块应用本文件的工具选择、图型和质量门槛。

## 基础处理与整合

1. 分样本完成质控、双细胞检测和环境RNA评估，保留原始 counts。
2. 多样本 AnnData 使用 `ad.concat(join="outer")`，预先唯一化基因名并给 barcode 加样本前缀。
3. 在相同质控细胞上分别运行 Harmony 与 scVI；独立聚类和注释，量化比较批次去除、生物学保留和跨供体稳定性。按综合效果二选一作为 primary，正式 Results 和报告只使用获选路线出图，另一条路线保留在 Processed 作为敏感性证据。
4. 疾病、表型或目标细胞状态不得作为待消除的 batch。

## 注释与恶性细胞门槛

先按主技能的最高优先级规则执行 `/share/skills/bio-scrna-cluster-annotation-audit/SKILL.md`，注释主要谱系，再对有足够供体支持的谱系二次聚类。每次注释必须执行 [annotation-composition-audit.md](annotation-composition-audit.md)，并在标签定稿后补齐 `scop` 细胞类型UMAP、细胞数和比例图。肿瘤项目先用 inferCNV 区分恶性、正常和不确定上皮，再开展恶性细胞亚型、差异、轨迹和调控分析。

## 关键细胞筛选

并行评估：

- 供体级细胞组成差异；
- 按供体分组交叉验证的 Augur 响应排名；
- 预定义基因集的 AUCell 活性及供体级汇总比较；
- 细胞类型内的 pseudobulk 差异；
- 跨供体复现、效应方向和医学合理性。

Augur衡量可分性，不代表效应大小。AUCell衡量基因集活性；若基因集来自同一数据，只能视作内部支持。把稳定离散群体称为亚型，把炎症、缺氧、增殖、耗竭等连续变化优先称为细胞状态。

## Marker 与正式差异

使用 Wilcoxon 或 `sc.tl.rank_genes_groups` 做注释和marker发现。病理组与对照组的正式差异以“供体 × 细胞类型/状态”的 pseudobulk counts 配合 edgeR、DESeq2 或 limma-voom完成；必要时使用含供体随机效应的混合模型。

## 拟时序方法评估与四选一

先确认同一合理谱系内存在连续过程，并满足：根节点有独立生物学依据、连续状态由多个供体贡献、轨迹不由单供体、批次、细胞周期或整合伪影驱动。先完成方法选择表，只实施 DPT、Monocle3、Slingshot 或 CellRank 中的一种；不把多方法堆叠当作证据增强。四种方法均不满足时停止分析，交付空结果、门槛失败项和原因。

### 方法选择表

逐项记录研究问题、预期拓扑、根节点依据、终末状态需求、spliced/unspliced 可用性与速度质控、聚类稳定性、低维连续性、各供体覆盖、软件生态和最终选择理由：

- 选择 **DPT**：目标是基于邻接图获得轻量、稳健的相对细胞顺序，已有可信根细胞，主要关注单一连续过程或有限分支，不要求显式谱系曲线、终末命运概率或RNA velocity。
- 选择 **Monocle3**：需要学习主图并展示较复杂的分支拓扑，细胞在低维空间形成可解释的连通结构，且根节点能够独立指定。这里的 `Monocle` 默认指 Monocle3；仅在项目明确要求复现旧流程时使用 Monocle2。
- 选择 **Slingshot**：细胞聚类稳定、谱系起点和候选终点有依据，需要由cluster关系拟合一条或多条平滑谱系曲线，并计划用分支权重或 tradeSeq 分析动态基因。
- 选择 **CellRank**：核心问题是方向性状态转移、终末命运概率或命运驱动基因，并具有通过质控的 spliced/unspliced 速度信息、实验时间先验或可独立成立的 CytoTRACE 方向信息。只有速度层通过质控时才称为RNA velocity证据。

若 CellRank 必须依赖 DPT、Monocle3 或 Slingshot 生成的 pseudotime 才能构造 `PseudotimeKernel`，则已构成多方法链路，不符合本项目“一种方法”规则；改选生成该 pseudotime 的方法，或在明确获准扩展方法后再使用 CellRank。

### 唯一方法的执行与审查

1. 冻结最终细胞标签、纳入谱系、低维表示、根节点和排除标准，再运行所选方法。
2. 输出细胞顺序或命运结果、谱系/终末结构、供体覆盖、关键参数和可复现源表；只交付所选方法的正式图。
3. 在所选方法内部对根节点、聚类分辨率、整合表示和关键参数做敏感性分析；不得在正式结果中追加第二种拟时序方法。
4. 检查顺序或终末状态是否由单供体、批次、细胞周期或细胞数主导。门槛失败时降级为探索结果或停止下游动态基因分析。
5. 横断面拟时序只表述为状态连续性假说，不表述为患者真实病程、细胞真实时间迁移或因果方向。

## pySCENIC 与 decoupler

- 在关键细胞谱系或经 inferCNV 净化的恶性细胞中运行 pySCENIC；记录数据库、物种、版本、随机种子和跨供体稳定性。
- 区分TF表达、regulon AUC、motif支持和直接结合证据。仅在拟时序门槛通过时，把regulon活性映射到唯一获选方法产生的 pseudotime 或命运概率。
- 使用decoupler/decoupleR配合版本固定的CollecTRI或DoRothEA估计TF活性，配合PROGENy估计通路活性；记录方法如ULM、MLM或consensus。
- pySCENIC与decoupler使用相同表达数据时属于多方法一致性，不属于独立验证。避免把当前数据推断的regulon再次作为唯一decoupler资源造成循环论证。

## 细胞通讯

关键细胞稳定后再比较条件间发送—接收关系。执行CellChat及其出图时，先完整读取 `/share/lijl/cellchat_pipeline/README.md`、`config.yaml` 和与所需图型对应的 `cellchat_analysis.R` 函数，把它们作为图型覆盖与参数化实现参考；替换示例路径、条件、物种和细胞类型，并复核每项统计适用性。该参考实现的导出meta只有cell type，直接合并条件得到的网络边数、概率、中心性和rankNet只作描述性计算结果；正式省标项目必须保留 `sample_id`/`donor_id`，先交付LR、通路、count/weight和中心性源表，再用供体级重复、pseudobulk方向或独立重复支持条件结论。非负量使用单向色标，带方向的差异使用零中心发散色标；无有效互作或差异不足时交付空表和原因，不生成占位图。CellChat、CellPhoneDB或NicheNet给出潜在通讯关系，不证明空间接触或因果信号。
