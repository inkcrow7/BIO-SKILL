# 细胞注释与组成医学常识审查

本文件只补充省标项目的注释后展示与组成审查。注释判定、标签变更和空间审计首先遵循 `/share/skills/bio-scrna-cluster-annotation-audit/SKILL.md`；冲突时直接以该外部技能通过审计后的最终标签覆盖当前注释。

覆盖必须可追溯：保留原注释字段，新增或更新最终注释字段，交付 `cluster_annotation_changes.tsv`，逐cluster记录旧标签、新标签、marker证据、UMAP/邻域证据、复核结论、置信度和下游重算状态。所有依赖旧标签的结果在重算前标记为失效，不得与新标签结果混用。

## 强制审查流程

1. 登记器官、解剖部位、疾病、取材方式、消化方案和富集/分选策略。
2. 按样本和供体输出细胞类型数量、比例、绝对保留数及分组分布；总体比例只能作总览。
3. 依据正向marker、排除marker、marker组合和功能程序审查每个标签，避免单marker注释。
4. 对照该组织通常存在的主要细胞、罕见细胞、疾病可扩增细胞和理论上不应出现的细胞。
5. 检查异常群是否由单供体、单批次、低质量、高线粒体、环境RNA或双细胞驱动。
6. 将标签分为 `supported`、`provisional`、`unknown` 和 `doublet_suspect`；证据不足时保留Unknown，不强制命名。

## 髓系默认标注层级

脑或中枢神经系统肿瘤的髓系二次注释默认使用身份—状态双层结构：主身份层固定为 `TAM`、`Monocyte`、`Microglia` 三个大类，状态层另列。先以主身份层完成 UMAP、比例、差异、轨迹和交付报告，再按研究问题决定是否展示状态层。

- `Microglia`：由 P2RY12、TMEM119、GPR34、SALL1、OLFML3、CX3CR1 等驻留小胶质组合支持，并排查 S100A8/A9/A12、FCN1、VCAN 等单核程序和 APOC1、SPP1、GPNMB 等 TAM 程序。
- `Monocyte`：由 S100A8、S100A9、S100A12、FCN1、VCAN、CCR2、CTSS、LYZ 等组合支持，并排查驻留小胶质和成熟巨噬程序。
- `TAM`：作为肿瘤相关巨噬细胞大类，由 APOC1、APOE、TREM2、GPNMB、SPP1、LGALS3、MSR1、CD163、MRC1 等组合及非单核、非稳态小胶质证据支持。
- APC、Cycling、IFN、MES、SPP1、缺氧、应激等属于状态或功能程序，记录在 `myeloid_state` 等独立字段；主身份字段不得把这些状态与 `TAM`、`Monocyte`、`Microglia` 并列。
- 原细分标签可折叠到三类主身份，但必须保留 cluster-to-class 映射、正向/排除 marker、供体覆盖和双整合一致性；无法解释的低质量或双细胞嫌疑群仍按审计规则保留待定，不为消除 Unknown 强制命名。
- 非脑/CNS 项目不使用 `Microglia` 作为默认类别；根据组织来源采用 Macrophage、Monocyte、DC 或更保守的 `Myeloid`，并报告实际注释分辨率。

完成标准：脑/CNS 肿瘤髓系正式主标签只含 `TAM`、`Monocyte`、`Microglia`（另加有明确审计原因的待定/双细胞标签）；所有功能状态位于独立字段，且三类均有多 marker、排除 marker、跨供体和双路线证据。

## 异常占比触发规则

阈值只用于触发人工复核，不用于自动删除：

- Unknown总体或任一样本占比较高，或在某个分组系统性升高；
- 某细胞类型占据样本大多数，但不符合解剖部位或取材方式；
- 某亚型绝大多数细胞来自单一供体；
- 理论罕见群体突然成为优势群，且marker不完整；
- 细胞比例与文库深度、线粒体比例、双细胞分数或批次高度相关；
- 对照组与病理组存在巨大比例差异，但只有很少供体支持。

## AT2 示例

AT2（肺泡Ⅱ型上皮）在肺实质或肺泡相关取材中可以丰富，需用 `SFTPC`、`SFTPA1/2`、`ABCA3`、`NAPSA` 等组合及阴性marker确认。在乳腺、脑、关节等非肺组织中出现大量AT2属于高优先级红旗，应依次排查：

1. 标签转移参考是否跨组织误配；
2. 乳腺腔面/分泌细胞是否因共享分泌程序被误标；
3. 环境RNA、双细胞或样本污染；
4. 基因符号、物种或参考注释映射错误；
5. 样本来源元数据是否登记错误。

证据不充分时改为上位谱系或Unknown，并保留复核记录；不得仅因医学上意外就直接删除真实细胞。

## Unknown 示例

Unknown大量出现时：

1. 查看每群top markers、marker组合和差异方向；
2. 按供体、批次、QC、双细胞分数和细胞周期分层；
3. 在合理谱系内重新归一化、降维和聚类；
4. 使用至少一种独立参考映射或人工marker复核；
5. 能确认上位谱系但不能确认亚型时使用如 `T_cell_unresolved`，不要虚构精细标签；
6. 仍无可靠证据时保留Unknown并限制其下游解释。

## 组成差异统计

以供体为重复单位，使用供体级比例、适当的组成模型或差异丰度方法；报告每组供体数、效应量、置信区间和多重校正。细胞级卡方检验不能替代供体级推断。

## 注释后强制 scop 出图

标签通过外部注释审计并覆盖写入最终元数据后，使用同一套最终标签、UMAP坐标、因子顺序和具名颜色生成正式图：

1. `scop::CellDimPlot` 全部细胞类型UMAP，保留图例；
2. `CellDimPlot(label=TRUE, label_insitu=TRUE, label_repel=TRUE)` 图上标签版；
3. 有实验分组时，输出按组拆分或逐组细胞类型UMAP，各图保持同一细胞类型颜色；
4. `scop::CellStatPlot(plot_type="bar", stat_type="count")` 细胞数图；
5. `CellStatPlot(plot_type="bar", stat_type="percent")` 细胞比例图，作为强制组成总览；
6. rose、ring和逐组pie仅作可选补充图，不替代供体级比例图与统计。

对 `Unknown`、待定或双细胞嫌疑标签，正式总览必须保留。确需输出排除版时，同时交付完整版本，并在文件名和源数据中明确排除规则。

若权威对象为AnnData/h5ad，外部注释技能仍按Scanpy/AnnData-first完成审计；为满足本项目的 `scop` 正式展示要求，可在标签定稿后构建只用于绘图的最小Seurat对象，保持细胞ID、最终标签、样本/供体、分组和UMAP一一一致，不回写或替换权威对象。

每张图交付PDF、白底300 dpi PNG和source.tsv。组成源表至少包含 `sample_id`、`donor_id`（如有）、`group`、`celltype`、`n_cells`、`sample_total_cells` 和 `proportion`。`CellStatPlot` 的合并细胞count/percent只作描述总览；正式组间组成推断仍以供体/样本为重复单位。

完成标准：外部注释审计图和表齐全；标签冲突已按最高优先级结论覆盖且变更表完整；依赖旧标签的结果已重算或明确失效；正式 `scop` UMAP、count bar、percent bar均有图形三件套；全部标签颜色覆盖完整；供体级组成表与图中计数可相互核对。

## 必交审计表

为每个标签记录：细胞数、总体比例、各供体比例、供体覆盖、正向marker、排除marker、参考来源、医学合理性、异常原因、复核操作、最终置信度和下游使用限制。异常AT2、Unknown及单供体主导群必须有逐项结论。
