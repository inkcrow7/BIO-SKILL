# Bulk—单细胞整合与机器学习

只在用户或参考方案明确纳入 Bulk–单细胞整合、候选基因汇合或机器学习时使用对应章节。本文件不自动触发跨组学交集或候选整合；方案未要求时，保持 Bulk 和单细胞结果独立。

## 证据层整合

不要直接拼接Bulk与单细胞表达矩阵。汇合以下证据：

- Bulk DEG方向和效应；
- Bulk GSEA leading-edge；
- 疾病相关WGCNA模块及模块成员度；
- 关键细胞pseudobulk差异；
- 细胞类型/状态特异marker；
- 唯一获选拟时序方法产生的动态基因或命运驱动基因；
- pySCENIC regulon和decoupler TF/通路活性；
- 细胞通讯配体—受体支持。

统一稳定基因ID、物种和方向。记录数据集是否独立。同一队列的多种算法只提高内部一致性，不提高独立验证等级。

## 候选优先级

建立证据矩阵而非只取硬交集。优先考虑：跨数据集方向一致、供体级显著、关键细胞定位明确、模块/通路一致、轨迹与调控关系连贯、外部队列复现。Venn或UpSet用于展示，不替代效应量和证据评分。

## 机器学习前置门槛

1. 明确预测单位是样本/患者，不是细胞。
2. 明确终点：二分类、连续表型或生存结局。
3. 检查样本量、事件数、类别不平衡、批次和缺失数据。
4. 优先在样本量较大的Bulk训练；单细胞提供候选基因、pseudobulk特征或程序评分。
5. 在建模前隔离外部验证集；外部集不得参与阈值、特征和超参数选择。

样本量不足时停止高维模型扩展，改做候选证据排序和验证性统计。

## LASSO、RF与SVM-RFE

- 二分类可使用逻辑LASSO/Elastic Net、随机森林和SVM-RFE。
- 生存结局改用Elastic Net Cox、随机生存森林和适用的生存SVM。
- 所有标准化、缺失处理、批次处理、特征过滤、特征选择和调参都必须在嵌套交叉验证的训练折内完成。
- 使用重复嵌套交叉验证或bootstrap统计入选频率与性能分布。
- 三种算法不是三个独立验证。不要默认取三者硬交集；使用稳定选择频率、至少两种算法支持和生物学证据分层。

## 评价与验证

二分类至少报告AUROC、AUPRC、敏感度、特异度和校准；生存模型报告C-index、时间依赖AUC和校准。明确区分训练、内部验证和锁定外部验证。最终基因必须保留模型系数或重要性、选择频率、方向、置信区间及外部表现。
