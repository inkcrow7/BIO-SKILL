# 聚类及注释完成后重新检测 marker

- 每次初次聚类、谱系二次聚类、细胞类型/亚型注释完成，或合并、拆分、过滤细胞及修改标签后，都基于当前定稿对象与最新分组重新运行 marker 检测。按最新 cluster 和最终注释标签分别生成适用的结果；不能只改旧 marker 表中的标签，也不能沿用上一版分组的检测缓存。
- 使用 Seurat `FindMarkers` 按每个当前分组逐一与其余细胞比较；覆盖全部分组时可使用内部逐组执行 marker 检测的 `FindAllMarkers`。记录实际调用函数。`findmarker` 是此处的任务称呼，不假定环境中存在同名函数；使用其他语言或封装对象时先核对真实接口，不能静默省略或仅输出固定 marker 的表达图。
- 显式设置用于 marker 检测的最新身份列与 RNA 表达 assay/layer；按具体检验选择正确的归一化表达或原始计数输入，不把 scVI 潜空间、整合矩阵或 Z-score 当作原始表达。仅重跑 marker 不要求重算已定稿 UMAP。
- 对每个分组记录比较对象、目标/参考细胞数、各样本贡献、表达比例、效应量、原始/校正 P 值及方法；保留实际已检验基因的 `.full.tsv`、按声明阈值筛选的 `.filtered.tsv` 和 top marker 摘要。说明预筛选范围，不能把 top N 表冒充完整检验结果。
- 运行记录保存输入对象、细胞清单/摘要、最新标签摘要、assay/layer、检验、阈值、随机种子及软件版本；缓存键包括分组标签、细胞集合、表达输入和参数。标签或细胞集合改变时原缓存失效。
- 用新 marker 结果复查注释和群间边界，再同步 marker 表、注释映射、表达图、图形索引及报告。若核验后再次修订标签，在该修订版上重新检测。
- 该步骤用于簇/细胞类型的注释核验；细胞级 marker 的 P 值不能作为疾病组间的生物学重复推断。正式条件差异仍按 donor/sample 等生物学重复建模。
- 全部检测完成、结果表与当前标签一致，才将该版聚类/注释视为完成；随后运行主 skill 指定的注释可视化入口。
