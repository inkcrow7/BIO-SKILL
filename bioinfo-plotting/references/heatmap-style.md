# 通用表达与注释热图

先区分矩阵语义：表达量、评分、行 Z-score、相关系数、后验概率使用各自明确的图例。一般表达或临床注释矩阵用 ComplexHeatmap；真正的 COMPASS 结果或明确要求该布局时读 [COMPASS 分支](matrix-correlation-heatmaps.md)，regulon 热图读 [Marsilea 分支](regulon-plots.md)，模块与富集组合读 [模块图](clustergvis.md)。

- 对齐行列 ID 和注释，保留最终排序表。单细胞组间热图先按样本/细胞类型汇总，再按设计汇总组；采用等样本权重，避免细胞多的样本主导。
- 所有注释轨道共享同一列顺序；分类配色使用有名字的完整映射。表达、评分和分组顺序沿用项目配置。
- 有符号且零点有意义的矩阵采用负蓝、零白、正红的发散色；相关系数固定 [-1,1]。非负表达/AUC 用 Reds 或 magma 等顺序色，图例写明单位、变换与范围。
- 行 Z-score 与未缩放汇总矩阵分别保留，标注缩放方向。常数行标记并按规则剔除；缺失值保持可识别状态，不能当作零表达。
- 明确距离、聚类方法和是否聚类；固定比较图的尺度和顺序。画布随行列数调整，矩阵单元尽量保持方形，标签可读且不裁切；不添加 title/subtitle。
- 细胞级热图用于描述分布；如抽样，记录每个样本/细胞类型的抽样策略、数量和随机种子。不能用抽样细胞替代生物学重复。
- 空结果写明原因，不生成伪造或占位热图。图名和 PDF/PNG 导出遵循主 skill，矩阵、注释、排序放入已有结果表体系。
