# 统计适用性与交付

## 推断单位与模型

- sample/donor 是独立生物学重复。细胞、模块内基因、技术重复不扩充 n；缺少可靠重复标识时仅做描述。任何一组只有一个生物学重复时不进行该对比的总体显著性推断；各组均 n=1 时可用单样本代表组展示变化。
- 两个重复是否可检验取决于方法与设计，不能声称稳定；更多独立重复通常更可靠，不把固定数量当作所有模型的充分条件。细胞类型内重新核对各组可用样本及细胞门槛。
- 配对/重复受试者保留配对或随机效应，batch 与组完全混杂时标记不可识别。单细胞组间表达推断采用 raw-count pseudobulk 或适合重复结构的模型。
- 完整表保留不合格对比及 eligibility/notes，P/q/CI 等无依据字段记 NA；筛选表排除无效推断。多重校正在预先定义的检验家族内进行，声明 BH 等方法。
- 有效表达量/评分对比同时展示显著性符号与精确数值，明确标记对应原始 P 还是调整 q；图、表采用同一字段和阈值。

## 表与运行记录

- 结果表按任务保留 gene/score、cell_type、contrast、groups、各组 biological_n/cell_n、summary、effect_type/effect、eligibility、test/model、P、q、CI、significance、notes。矩阵热图另保留矩阵、注释、排序及颜色映射；相关性保留配对 n 和缺失策略。
- 复用项目已有 Tables 表体系，必要时新增语义清楚的 `.full.tsv` 和筛选表；不额外制造与结果表重复的 `source.tsv` 或 `_source.tsv`。
- 在运行记录中保存输入来源及必要校验、矩阵层、物种/ID、变换、样本和分组规模、模型设计、参数、随机种子、包版本、兼容补丁和省略原因。中间矩阵与日志按项目规范进入 Processed 等位置。
- 图片名、PDF + 300 dpi PNG、无标题和独立输出要求以主 SKILL.md 为唯一命名及导出规则。`Tables/figure_index.tsv` 关联语义图片路径、输入和对应统计表，报告引用一致。
- 检查 PNG/PDF 的标签裁切、字体、图例、统计数值与真实样本单位；空筛选结果可为空表并说明原因，不生成虚假图形。
