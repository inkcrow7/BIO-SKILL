# 表达量、marker、患者层面验证和基因相关性

按实际问题读取对应段落。基因表达量和评分遵循主 skill 的 `yt.pl.sc.save_gene_list_exprs`；专用汇总热图和相关性统计图使用各自入口。单细胞矩阵适配见 [数据口径](scrna-data.md)，推断资格见 [统计与交付](statistics-and-delivery.md)。只生成请求所需图形，不套用固定图册。

## bulk 表达量

- 先核实测量尺度：RNA-seq 采用适当归一化表达作展示，原始 counts 用于适当的计数模型；芯片使用已处理的表达值，确认是否 log2，避免二次取对数。多探针映射按预先声明规则确定性汇总。
- 数据至少关联 sample_id、group、expression，按设计保留 subject/pair、batch 和协变量。以组为横轴，箱线图展示分布并保留各生物学重复点，写明组 n 和表达单位。
- 推断使用相应 DESeq2/edgeR/limma 等模型的有效对比。图上简单检验不能替代已调整协变量的模型结果。
- PCA、样本相关性及表达分布仅在必要 QC 中使用。逐样本 QC 按样本分别输出内部图，不自动扩展成逐样本比较主题。
- 效应森林图明确使用模型 logFC、均值差或 Hedges g 等哪种尺度，提供适当 CI 和零参考线。Bootstrap 按生物学单位重采样，配对设计保持配对；2,000 次可作为起点并记录种子。
- ROC、leave-one-out 等只在明确的分类或稳健性任务中加入，遵循项目相应分析规范；表达量任务不自动增加这些分析。

## marker 与细胞类型表达

- 区分预先指定 marker、注释 marker 发现和组间差异基因，不能互相冒充。记录物种、ID 映射、缺失基因、筛选条件和排序规则；top N 与阈值按任务确定。
- DotPlot 颜色标明平均表达是所有细胞均值还是阳性细胞均值，点大小明确为阳性细胞百分比。组间比较按样本汇总并等样本加权，细胞级图标记为描述性。
- 基因 × 细胞类型/分组热图使用 [通用热图](heatmap-style.md)。展示 Z-score 时同时保留原汇总矩阵，尤其两组 Z-score 主要反映相对方向，不能代替效应大小。
- 小提琴图按基因分别输出，保持表达值范围；非负表达不延伸到负值。细胞分布不能支持患者层面的显著性。
- UMAP 使用定稿坐标和主 skill 指定入口。密度图仅在明确需要时选择适合的密度方法，不作为默认表达量图替代。

## 患者/样本层面验证

- 整理 sample/subject × group × cell_type × gene 的表，保留均值、中位数、阳性细胞数、总细胞数、阳性比例。最少细胞阈值按项目声明，记录被排除组合及原因。
- 正式目标是同一细胞类型内的组间比较；细胞类型用于分层。参考组和对比在看显著性前确定，避免按最大表达挑选参考组。
- 连续表达汇总按设计选择模型；重复患者使用配对或适当混合模型。阳性比例可按计数设计选择二项/存在过度离散时的 beta-binomial 模型；不把每个细胞当作独立患者。
- 图上保留各患者点。均值差/表达效应的森林图以零为参照；OR 用对数轴和 1 参照。表达强度与阳性比例分别解释，不能混用效应尺度。
- 输出 estimate、CI_low、CI_high、effect_scale、p、q、eligibility、model。推断不合格时保留描述值与原因，统计字段为 NA。

## 基因与基因/评分的相关性

- bulk 一对数据来自同一生物学样本；单细胞先按 donor/sample 和需要的细胞类型汇总，保留 paired n。不同队列分别分析，联合模型须有设计依据。
- 默认考虑 Spearman；Pearson 需适当尺度及线性关系依据。删除缺失配对并记录数量，恒定变量或 n 不足标记不可检验。
- 散点图展示生物学重复，按队列或细胞类型分别出图；不默认 facet 或拼成总图。趋势线与方法相符，记录 rho/r、n、P、BH q 和按生物学单位 bootstrap 的 95% CI。
- 多个相关检验按预先定义家族做 BH。森林图固定相关系数范围约 [-1,1] 并设零参考线，保留 CI、n、q 和预设顺序。
- 相关性矩阵用 [紧凑相关性热图](matrix-correlation-heatmaps.md)，不能将相关性写成因果或调控证据。
