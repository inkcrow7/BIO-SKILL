# 供体统计与候选筛选

## 共同轨迹上的条件比较

从 Joint CDS 导出每个 donor 的细胞数、条件和中位/均值拟时序；State 比例的分母为该 donor 全部入选谱系细胞，补齐零计数 State。正式统计以独立 donor 为单位，按设计做配对、秩和或适当模型，不用细胞级检验冒充疾病组间比较。

IPF 第60步示例要求 donor 至少10个入选细胞、每组至少3个合格 donor，比较中位拟时序与 State 比例；这些有效检验在同一声明家族做 BH。可画等 donor 权重的共同时间分箱分布，bootstrap 按 donor 重采样，保留各 bin 比例与置信区间。分箱网格和分母全组一致，曲线 CI 本身不是组间显著性。

门槛按项目设计预先声明，任何一组 n=1 仅作描述；其他 n 较少的设计按模型适用性记录。不默认逐样本建轨或比较独立模型的数值时间。配对/重复受试者设计需相应修改模板。

## 可选动态/上升候选筛选

仅任务需要时开启。从预先定义的候选全集出发；若引用 bulk DEG，记录队列、比较方向、阈值、稳定 ID 映射、缺失和检验全集。IPF 第67步使用当前 Joint 模型中的 IPF 细胞子集，保持 Joint 的 Pseudotime 和 size factors，不重建 IPF 独立轨迹。

1. 对有足够检出且不恒定的候选，用 `differentialGeneTest` 比较 `~sm.ns(Pseudotime, df=3) + donor` 对 `~donor`；保留 status、family、pval、原生 qval，并对当前候选的有效检验重新 BH。donor 固定效应的细胞级样条仍为探索性关联，不能替代重复层面推断。
2. 每 donor 内计算基因表达与共同拟时序的 Spearman rho；以独立 donor 的 rho 做预先指定方向的单侧 signed-rank 检验，并跨候选 BH。恒定或覆盖不足的 donor 排除并记录。
3. 在目标条件的总体共同拟时序上固定早/晚窗口，如全局前/后20%分位数；不能为每 donor 重新定义相对早晚来声称同一时间位置。每 donor 在两窗口都有足够细胞时，比较该 donor 的 Late−Early 表达均值差，再在 donor 层面做配对检验和 BH。
4. 供体均值与分箱表达使用原 counts 的 `log1p(CP10k)`，分母为完整 QC 基因 library total；不要和 Monocle size-factor 相对表达混淆。分箱时先 donor 内均值，再 donor 等权汇总，保留供体数、细胞数及覆盖门槛。

IPF 的严格上升候选同时满足：样条 FDR<0.05、donor 趋势 FDR<0.05 且中位 rho>0、配对阶段 FDR<0.05 且中位 Late−Early≥0.2 log1p(CP10k)、至少6个覆盖合格时间 bin。示例覆盖门槛为每 donor 趋势≥20细胞/≥5阳性细胞、早晚各≥3细胞、每组检验≥3 donor、每 bin≥3细胞且≥3 donor。这些值保存在配置，不为得到候选放宽，也不当作所有项目的统一阈值。

严格筛选为空，交付完整统计和空筛选表并说明；只有任务明确需要探索图时另建探索候选标识，不能把探索结果替代严格名单。动态关联、共同表达、分支状态均不构成因果驱动结论。

## 表与数值

保留所有候选、检验资格/排除原因、有效样本量、全模型/简化模型、P/FDR、配对/校正家族、效应和覆盖；统计数字与图一致。非零小 P/FDR 用足够有效数字或科学计数法，不因小数位显示成0。作图曲线与热图不额外附伪造显著性，统计适用性记为描述性/not_applicable。
